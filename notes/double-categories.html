Preorder Categories

Starting Definitions

Definition 1 (Pseudo Category object in the thin 2-category PreOrd)  

A Preorder Category \(\mathbb{C}\) is the data of:

  • A class sized preorder \(\mathcal{O}\) with relation symbol (\(\sqsubseteq\)), whose elements are called the objects of \(\mathbb{C}\);

  • For each pair of objects \(x,y\) there is a set \(\text{hom}_{\lambda}(x,y)\) whose elements are called loose arrows e.g. \(f: x \not\rightarrow y\);

  • For each object \(x\) a distinguished loose arrow in \(\text{hom}_{\lambda}(x,x)\) written \(\text{id}_x : x \not\rightarrow x\);

  • For each triple of objects \(x, y, z\) and loose arrows \(f: x \not\rightarrow y\), \(g : y \not\rightarrow z\) there is a loose arrow \(g \circ f: x \not\rightarrow z\);

  • For each quadruple of objects \(x' \sqsubseteq x\), \(y' \sqsubseteq y\) and loose arrows \(f: x \not\rightarrow y\), \(f': x' \not\rightarrow y'\) there is at most one arrow from \(f\) to \(f'\) written \(f' \sqsubseteq f\);

  • For each pair of objects \(x,y\) and loose arrow \(f : x \not\rightarrow y\) then \(f \sqsubseteq f\);

  • For each pair of objects \(x' \sqsubseteq x\) then \(\text{id}_{x'} \sqsubseteq\text{id}_x\);

  • For each pair of objects \(x, y\) and loose arrow \(f: x \not\rightarrow y\), then

\[f \circ \text{id}_x \sqsubseteq f \sqsubseteq f \circ \text{id}_x \quad \text{and} \quad \text{id}_y \circ f \sqsubseteq f \sqsubseteq\text{id}_y \circ f;\]

  • For each quadruple of objects \(x, y, z, w\) and loose arrows \(f: x \not\rightarrow y\), \(g : y \not\rightarrow z\), \(h : z \not\rightarrow w\), then

\[(h \circ g) \circ f \sqsubseteq h \circ (g \circ f) \sqsubseteq(h \circ g) \circ f;\]

  • For each hextuple of objects \(x'' \sqsubseteq x' \sqsubseteq x\), \(y'' \sqsubseteq y' \sqsubseteq y\) and loose arrows \(f : x \not\rightarrow y\), \(f' : x' \not\rightarrow y'\), \(f'' : x'' \not\rightarrow y''\) with \(f' \sqsubseteq f\) and \(f'' \sqsubseteq f'\) then \(f'' \sqsubseteq f\);

  • For each hextuple of objects \(x' \sqsubseteq x\), \(y' \sqsubseteq y\), \(z' \sqsubseteq z\) and loose arrows \(f: x \not\rightarrow y\), \(g: y \not\rightarrow z\), \(f': x' \not\rightarrow y'\), \(g' : y' \not\rightarrow z'\) such that \(f' \sqsubseteq f\) and \(g' \sqsubseteq g\) then \(g' \circ f' \sqsubseteq g \circ f\).

Remark 1 (Simplified Notation).

For the sake convenience it is useful to introduce the notation:

\[x \simeq x' \quad \iff \quad x' \sqsubseteq x \sqsubseteq x'\]

on objects in a preorder category and

\[ f \simeq f' \quad \iff \quad f' \sqsubseteq f \sqsubseteq f'\]

on loose arrows, read as \(x\) is equivalent to \(x'\) and \(f\) is equivalent to \(f'\).

Then in the definition above we would replace with

\[f \circ \text{id}_x \simeq f \quad \text{and} \quad \text{id}_y \circ f \simeq f\]

as well as

\[(h \circ g) \circ f \simeq h \circ (g \circ f).\]

Definition 2 (Preorder oplax functors between preorder categories)  

Let \(\mathbb{C}\) and \(\mathbb{C}^{\gimel}\) be two preorder categories a preorder oplax functor between them, written \(F : \mathbb{C} \rightarrow \mathbb{C}^{\gimel}\), is the data of:

  • An order preserving function \(F^{\text{o}} : \mathcal{O} \rightarrow \mathcal{O}^{\gimel}\);

  • For each pair of objects \(x, y \in \mathcal{O}\) and loose arrow \(f : x \not\rightarrow y\) there is a loose arrow \(F^{\lambda}_{x, y}(f): F^{\text{o}}x \not\rightarrow F^{\text{o}}y\);

  • For each quadruple of objects \(x' \sqsubseteq x\), \(y' \sqsubseteq y\) and loose arrows \(f: x \not\rightarrow y\), \(f': x' \not\rightarrow y'\) such that \(f' \sqsubseteq f\) then

\[F^{\lambda}_{x',y'}(f') \sqsubseteq^{\gimel} F^{\lambda}_{x,y}(f);\]

  • For each object \(x \in \mathcal{O}\) then

\[\text{id}^{\gimel}_x \sqsubseteq^{\gimel} F^{\lambda}_{x,x}(\text{id}_x);\]

  • For each triple of objects \(x, y, z \in \mathcal{O}\) and loose arrows \(f: x \not\rightarrow y\), \(g: y \not\rightarrow z\) then

\[F^{\lambda}_{y,z}(g) \circ^{\gimel} F^{\lambda}_{x,y}(f) \sqsubseteq^{\gimel} F^{\lambda}_{x,z}(g \circ f).\]

Remark 2 (psuedo preorder functor).

We would have the definition of a psuedo preorder functor by tweaking the above definition in the following way: (we replace with)

\[F^{\lambda}_{x',y'}(f') \simeq^{\gimel} F^{\lambda}_{x,y}(f),\]

\[\text{id}^{\gimel}_{F^{\text{o}}x} \simeq^{\gimel} F^{\lambda}_{x,x}(\text{id}_x),\]

\[\text{and} \quad F^{\lambda}_{y,z}(g) \circ^{\gimel} F^{\lambda}_{x,y}(f) \simeq^{\gimel} F^{\lambda}_{x,z}(g \circ f).\]

Remark 3 (Composition of psuedo preorder functors).

Given three preorder categories \(\mathbb{C}\), \(\mathbb{C}^{\gimel}\), \(\mathbb{C}^{\beth}\) and psuedo preorder functors \(F : \mathbb{C}\rightarrow \mathbb{C}^{\gimel}\), \(G: \mathbb{C}^{\gimel} \rightarrow \mathbb{C}^{\beth}\) then define their composition

  • The underlying order preserving function \((G\circ F)^{\text{o}} \triangleq G^{\text{o}}\circ F^{\text{o}} : \mathcal{O} \rightarrow \mathcal{O}^{\beth}\);

  • For each pair of objects \(x,y \in \mathcal{O}\) and loose arrow \(f: x \not\rightarrow y\) then define

\[(G \circ F)^{\lambda}_{x,y}(f) \triangleq G^{\lambda}_{F^{\text{o}}x,F^{\text{o}}y}(F^{\lambda}_{x,y}(f)) : G^{\text{o}}(F^{\text{o}}x) \not\rightarrow G^{\text{o}}(F^{\text{o}}y).\]

Definition 3 (Comparing two oplax preorder functors through the order)  

Given preorder categories \(\mathbb{C}\), \(\mathbb{C}^{\gimel}\) as well as a pair of oplax preorder functors \(F :\mathbb{C}\rightarrow \mathbb{C}^{\gimel}\), \(G: \mathbb{C}\rightarrow \mathbb{C}^{\gimel}\) then a \(\sqsubseteq\)-transformation from \(F\) to \(G\), written \(G \sqsubseteq F\), are the following assertions

  • For each object \(x \in \mathcal{O}\), \(G^{\text{o}}x \sqsubseteq^{\gimel} F^{\text{o}}x\);

  • For each pair of objects \(x, y \in \mathcal{O}\) and \(f : x \not\rightarrow y\) then \(G^{\lambda}_{x,y}(f) \sqsubseteq^{\gimel} F^{\lambda}_{x,y}(f)\).

Definition 4 (Comparing two oplax preorder functors loosely)  

Given preorder categories \(\mathbb{C}\), \(\mathbb{C}^{\gimel}\) as well as a pair of oplax preorder functors \(F :\mathbb{C}\rightarrow \mathbb{C}^{\gimel}\), \(G: \mathbb{C}\rightarrow \mathbb{C}^{\gimel}\) then a loose transformation from \(F\) to \(G\), written \(\alpha : F \not\rightarrow G\), is the following data

  • For each object \(x \in \mathcal{O}\) a loose arrow \(\alpha_x : F^{\text{o}}x \not\rightarrow G^{\text{o}}x\);

  • For each pair of objects \(x' \sqsubseteq x\) in \(\mathcal{O}\) then \(\alpha_{x'} \sqsubseteq\alpha_x\).

This data is required to satisfy:

  • For each pair of objects \(x, y\) in \(\mathcal{O}\) and loose arrow \(f : x \not\rightarrow y\)

\[\alpha_y \circ^{\gimel} F^{\lambda}_{x,y}(f) \simeq G^{\lambda}_{x,y}(f) \circ^{\gimel} \alpha_x.\]

Definition 5 (Comparing loose transformations)  

Given preorder categories \(\mathbb{C}\), \(\mathbb{C}^{\gimel}\) and a quadruple of oplax preorder functors \(H \sqsubseteq F : \mathbb{C}\rightarrow \mathbb{C}^{\gimel}\), \(K \sqsubseteq G : \mathbb{C}\rightarrow \mathbb{C}^{\gimel}\) and loose transformations \(\alpha : F \not\rightarrow G\), \(\beta : H \not\rightarrow K\) then there is modification from \(\alpha\) to \(\beta\), written \(\beta \sqsubseteq\alpha\), when for each object \(x \in \mathcal{O}\) we have that \(\beta_x \sqsubseteq\alpha_x\).

Definition 6 (When is a preorder category an Equipment)  

Let \(\mathbb{C}\) be a preorder category, we say

  • if for a pair \(y \sqsubseteq x\) there is a loose arrow \(g^{\flat} : y \not\rightarrow x\) such that \(\text{id}_y \sqsubseteq g^{\flat} \sqsubseteq\text{id}_x\) then \(g^{\flat}\) is called the pairs’ (\(y \sqsubseteq x\)) conjoint;

  • if for a pair \(y \sqsubseteq x\) there is a loose arrrow \(g^{\sharp} : x \not\rightarrow y\) such that \(\text{id}_y \sqsubseteq g^{\sharp} \sqsubseteq\text{id}_x\) then \(g^{\sharp}\) is called the pairs’ (\(y \sqsubseteq x\)) companion.

We call \(\mathbb{C}\) an eqiupment if every pair \(y \sqsubseteq x\) has a companion and a conjoint.

Definition 7 (A special (pronounced spee-shal) square less than transformation)  

Let \(\mathbb{C}, \mathbb{C}^{\gimel}\) be two preorder categories and \(G \sqsubseteq F : \mathbb{C}\rightarrow \mathbb{C}^{\gimel}\) be a \(\sqsubseteq\)-transformation between oplax preorder functors. We say this transformation is special if for each \(x \in \mathcal{O}\), \(G^{\text{o}}x \sqsubseteq F^{\text{o}}x\) has a companion \(g^{\sharp}_x : F^{\text{o}}x \not\rightarrow G^{\text{o}}x\) in \(\mathbb{C}^{\gimel}\) which satisfies for each \(x,y \in \mathcal{O}\) and loose arrow \(f : x \not\rightarrow y\),

\[G^{\lambda}_{x,y}(f) \circ^{\gimel} g^{\sharp}_x \simeq^{\gimel} g^{\sharp}_y \circ^{\gimel} F^{\lambda}_{x,y}(f).\]

Definition 8 (Products of Preorder Categories)  

Given a pair of preorder categories \(\mathbb{C}\) and \(\mathbb{C}^{\gimel}\) we can form a new preorder category which is their product, \(\mathbb{C}\times \mathbb{C}^{\gimel}\), consisting of the data:

  • The class \(\mathcal{O}^{\times} \triangleq \mathcal{O}\times\mathcal{O}^{\gimel}\) with the componentisewise order;

  • For each pair, of pairs, of objects \((x_1,x_2)\) and \((y_1,y_2)\) the set

\[\text{hom}_{\lambda}^{\times}((x_1,x_2),(y_1,y_2)) \triangleq \text{hom}_{\lambda}(x_1,x_2) \times \text{hom}_{\lambda}^{\gimel}(y_1,y_2);\]

  • For each object \((x_1,x_2)\) a distinguised loose arrow \(\text{id}^{\times}_{(x_1,x_2)} \triangleq (\text{id}_{x_1}, \text{id}^{\gimel}_{x_2})\);

  • For each triple \((x_1,x_2), (y_1,y_2), (z_1,z_2)\) and loose arrows \((f_1,f_2) : (x_1,x_2) \not\rightarrow(y_1,y_2), (g_1,g_2) : (y_1,y_2) \not\rightarrow(z_1,z_2)\) there is a loose arrow

\[(g_1,g_2) \circ^{\times} (f_1,f_2) \triangleq (g_1 \circ f_1, g_2 \circ^{\gimel} f_2) : (x_1,x_2) \not\rightarrow(z_1,z_2);\]

  • For each quadruple \((x_1',x_2') \sqsubseteq^{\times} (x_1,x_2), (y_1',y_2') \sqsubseteq^{\times} (y_1,y_2)\) and loose arrows \((f_1,f_2): (x_1,x_2) \not\rightarrow(y_1,y_2), (f_1', f_2') : (x_1',x_2') \not\rightarrow(y_1',y_2')\) there is an arrow

\[(f_1', f_2') \sqsubseteq^{\times} (f_1, f_2) \iff \quad f_1' \sqsubseteq f_1 \quad \land \quad f_2' \sqsubseteq^{\gimel} f_2.\]

Theorem 1 (The product of preorder categories is a preorder category)  

This is a simple checking that the definitions given above are enough to conclude the rest of the assertions.

For example, given objects \((x_1,x_2), (y_1,y_2)\) and a loose arrow \((f_1,f_2) : (x_1,x_2) \not\rightarrow(y_1,y_2)\) then we have that \((f_1,f_2) \sqsubseteq^{\times} (f_1,f_2)\) as we have that both \(f_1 \sqsubseteq f_1\) and \(f_2 \sqsubseteq^{\gimel} f_2\) hold.

Definition 9 (The thin 2-category of preorder categories)  

Let \(ps\mathcal{P}\text{re}\mathcal{O}rd\mathcal{C}at\) denote the monoidal (thin) 2-category with:

  • 0-cells: Preorder categories \((\mathbb{C}, \mathbb{C}^{\gimel}, \mathbb{C}^{\beth}, \mathbb{D},...)\);

  • 1-cells: psuedo preorder functors \((F: \mathbb{C} \rightarrow \mathbb{C}^{\gimel}, G : \mathbb{C}^{\gimel} \rightarrow \mathbb{C}^{\beth},...)\);

  • 2-cells: \(\sqsubseteq\)-transformations between psuedo preorder functors (\(G \sqsubseteq F : \mathbb{C} \rightarrow \mathbb{C}^{\gimel}\)).

and monoidal product the product of preorder categories defined above.

Definition 10 (Monoidal Preorder Category)  

A monoidal preorder category is a preorder category \(\mathbb{C}\) with a distinguished object \(1 \in \mathcal{O}\) with a loose arrow \(\nu : 1 \not\rightarrow 1\) and an assignment:

  • For each pair of objects \(x_1,x_2\) an object \(x_1 \otimes x_2\);

  • For each quadruple of objects \(x_1, x_2, y_1, y_2\) and loose arrows \(f_1 : x_1 \not\rightarrow y_1\), \(f_2 : x_2 \not\rightarrow y_2\) a loose arrow \(f_1 \otimes f_2 : x_1 \otimes x_2 \not\rightarrow y_1 \otimes y_2\).

This assignment must satisfy the following properties:

  • For each quadruple \(x_1' \sqsubseteq x_1\), \(x_2' \sqsubseteq x_2\) then \(x_1'\otimes x_2' \sqsubseteq x_1 \otimes x_2\);

  • For each octuple \(x_1' \sqsubseteq x_1\), \(x_2' \sqsubseteq x_2\), \(y_1' \sqsubseteq y_1\), \(y_2' \sqsubseteq y_2\) and quadruple of loose arrows \(f_1' : x_1' \not\rightarrow y_1'\), \(f_2' : x_2' \not\rightarrow y_2'\), \(f_1 : x_1 \not\rightarrow y_1\), \(f_2 : x_2 \not\rightarrow y_2\) such that \(f_1' \simeq f_1\) and \(f_2' \simeq f_2\) then

\[f_1' \otimes f_2' \simeq f_1 \otimes f_2;\]

  • For each pair of objects \(x_1, x_2\) then \(\text{id}_{x_1 \otimes x_2} \simeq \text{id}_{x_1} \otimes \text{id}_{x_2};\)

  • For each hextuple \(x_1, x_2, y_1, y_2, z_1, z_2\) and quadruple of loose arrows \(f_1 : x_1 \not\rightarrow y_1\), \(f_2 : x_2 \not\rightarrow y_2\), \(g_1 : y_1 \not\rightarrow z_1\), \(g_2 : y_2 \not\rightarrow z_2\) then

\[(g_1 \otimes g_2) \circ (f_1 \otimes f_2) \simeq (g_1 \circ f_1) \otimes (g_2 \circ f_2);\]

  • For each hextuple \(x_1, x_2, x_3, y_1, y_2, y_3\) and loose arrows \(f_1 : x_1 \not\rightarrow y_1\), \(f_2 : x_2 \not\rightarrow y_2\), \(f_3: x_3 \not\rightarrow y_3\) then

\[(x_1 \otimes x_2) \otimes x_3 \simeq x_1 \otimes (x_2 \otimes x_3)\]

\[ \text{and} \quad (f_1 \otimes f_2) \otimes f_3 \simeq f_1 \otimes (f_2 \otimes f_3);\]

The assignment interacts with the distinguished object through \(\nu \simeq \text{id}_{1}\) and

  • For each object \(x\), \(1 \otimes x \simeq x\) and \(x \otimes 1 \simeq x\).

Definition 11 (lax Monoidal Preorder Functors)  

Given \((\mathbb{C}, \otimes, 1)\) and \((\mathbb{C}^{\gimel}, \otimes^{\gimel}, 1^{\gimel})\) monoidal preorder categories. A lax monoidal preorder functor \(F : (\mathbb{C}, \otimes, 1) \rightarrow (\mathbb{C}^{\gimel}, \otimes^{\gimel}, 1^{\gimel})\) is a pseudo preorder functor \(F : \mathbb{C}\rightarrow \mathbb{C}^{\gimel}\) along with the data:

  • For each \(x_1,x_2 \in \mathcal{O}\), \(F^{\text{o}}(x_1 \otimes x_2) \sqsubseteq^{\gimel} F^{\text{o}}x_1 \otimes^{\gimel} F^{\text{o}}x_2\);

  • For each quadruple \(x_1, x_2, y_1, y_2 \in \mathcal{O}\) along with loose arrows \(f_1 : x_1 \not\rightarrow y_1, f_2 : x_2 \not\rightarrow y_2\) then \(F^{\lambda}_{x_1 \otimes x_2, y_1 \otimes y_2}(f_1 \otimes f_2) \sqsubseteq^{\gimel} F^{\lambda}_{x_1,y_1}(f_1) \otimes^{\gimel} F^{\lambda}_{x_2,y_2}(f_2)\);

  • Furthermore, \(F^{\text{o}} 1 \sqsubseteq^{\gimel} 1^{\gimel}\) (and \(F^{\lambda}_{1, 1}(\text{id}_1) \sqsubseteq^{\gimel} \text{id}_{1^{\gimel}}\) which is guaranteed by the axioms of pseudo preorder functor).

Definition 12 (Monoidal Loose Transformation) Let \(F\) and \(G : (\mathbb{C}, \otimes, 1) \rightarrow (\mathbb{C}^{\gimel}, \otimes^{\gimel}, 1^{\gimel})\) be two monoidal preorder functors between monoidal preorder categories. A monoidal loose transformation \(\beta : F \not\rightarrow G\) is a loose transformation endowed with the properties

  • For each \(x_1, x_2 \in \mathcal{O}\), \(\beta_{x_1 \otimes x_2} \sqsubseteq\beta_{x_1} \otimes^{\gimel} \beta_{x_2}\);

  • and \(\beta_1 \sqsubseteq\text{id}_{1^{\gimel}}\).

Definition 13 (Exponential Preorder Category)  

Given \(\mathbb{X}\) a (small) preorder category and \(\mathbb{C}\) some other preorder category.

  • Consider the class

\[\mathcal{O}^{\text{ps}} \triangleq ps\mathcal{P}\text{re}\mathcal{O}rd\mathcal{C}at(\mathbb{X}, \mathbb{C})\]

of all psuedo preorder functors from \(\mathbb{X}\) to \(\mathbb{C}\) these will be the objects of the proposed exponential \((\mathbb{C}^{\mathbb{X}})\), with the preorder exactly given by \(\sqsubseteq\)-transformations;

  • For each pair of psuedo preorder functors \(F : \mathbb{X}\rightarrow \mathbb{C}, G : \mathbb{X}\rightarrow \mathbb{C}\) there is a set \(\text{hom}_{\lambda}^{\text{ps}}(F,G)\) which are \(\alpha : F \not\rightarrow G\) loose transformations;

  • For each \(F : \mathbb{X}\rightarrow \mathbb{C}\) there is \(\text{id}_F : F \not\rightarrow F\) with components for each \(x \in \mathcal{O}^{\mathbb{X}}\), \((\text{id}_F)_x \triangleq \text{id}_{F^\text{o}x}^{\mathbb{C}}\);

  • For each triple \(F : \mathbb{X}\rightarrow \mathbb{C}, G : \mathbb{X}\rightarrow \mathbb{C}, H : \mathbb{X}\rightarrow \mathbb{C}\) and loose transformations \(\alpha : F \not\rightarrow G, \beta : G \not\rightarrow H\) then there is a loose transformation with components for each \(x \in \mathcal{O}^{\mathbb{X}}\), \((\beta \circ \alpha)_x \triangleq \beta_x \circ^{\mathbb{C}} \alpha_x\);

  • For each quadruple \(F' \sqsubseteq F, G' \sqsubseteq G\) and loose transformations \(\alpha: F \not\rightarrow G, \alpha': F' \not\rightarrow G'\) then there is at most modification from \(\alpha\) to \(\alpha'\) written \(\alpha' \sqsubseteq\alpha\).

Theorem 2 (Exponentiating by a small preorder category gives a new preorder category)  

Once again we simply need to check the data defined above is sufficient.

For example, if we have a pair of psuedo preorder functors with \(G \sqsubseteq F : \mathbb{X}\rightarrow \mathbb{C}\), then for each \(x \in \mathcal{O}^{\mathbb{X}}\), \(G^{\text{o}}x \sqsubseteq^{\mathbb{C}} F^{\text{o}}x\) and so \(\text{id}_{G^{\text{o}}x}^{\mathbb{C}} \sqsubseteq^{\mathbb{C}} \text{id}_{F^{\text{o}}x}^{\mathbb{C}}\), which implies \(\text{id}_{G} \sqsubseteq\text{id}_F\).

Definition 14 (pseudo predorder endofunctors form a monoidal Preorder Category)  

Let \(\mathbb{X}\) be a small Preorder Category. We wish to put a monoidal structure on \(\mathbb{X}^{\mathbb{X}}\). To begin define the assignment on objects and loose arrows:

  • For each pair \(F_1 : \mathbb{X}\rightarrow \mathbb{X}, F_2 : \mathbb{X}\rightarrow \mathbb{X}\) then define \(F_1 \otimes F_2 \triangleq F_2 \circ F_1 : \mathbb{X}\rightarrow \mathbb{X}\);

  • For each quadruple \(F_1, F_2, G_1, G_2 : \mathbb{X}\rightarrow \mathbb{X}\) and a pair of loose transformatiomns \(\alpha : F_1 \not\rightarrow G_1\), \(\beta : F_2 \not\rightarrow G_2\) then there is a loose transformation \(\alpha \otimes \beta : F_1 \otimes F_2 \not\rightarrow G_1 \otimes G_2\). Which has components, for each \(x \in \mathcal{O}^{\mathbb{X}}\), defined as

\[(\alpha \otimes \beta)_x \triangleq \beta_{G_1^{\text{o}} x} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F^{\text{o}}_1 x, G^{\text{o}}_1 x}(\alpha_x);\]

Also define the unit as \(\text{id}_{\mathbb{X}}\) the identity pseudo preorder functor on \(\mathbb{X}\) and \(\nu : \text{id}_{\mathbb{X}} \not\rightarrow\text{id}_{\mathbb{X}}\), which for each \(x \in \mathcal{O}^{\mathbb{X}}\) is defined componentwise \(\nu_x = \text{id}_{x}\).

Lemma 1 (Verify the assignment on loose transformations does produce a loose transformation)  

  • For each pair of objects \(x' \sqsubseteq x\) in \(\mathcal{O}^{\mathbb{X}}\) we have as \(G_1^{\text{o}}x' \sqsubseteq G_1^{\text{o}}x\) and by \(\beta\) being a loose transformation

\[\beta_{G_1^{\text{o}}x'} \sqsubseteq\beta_{G_1^{\text{o}}x}.\]

Furthermore, \(\alpha_{x'} \sqsubseteq\alpha_x\) as \(\alpha\) is a loose transformation, thus

\[(F_2)^{\lambda}_{F_1^{\text{o}}x', G_1^{\text{o}}x'}(\alpha_{x'}) \sqsubseteq(F_2)^{\lambda}_{F_1^{\text{o}}x, G_1^{\text{o}}x}(\alpha_{x}).\]

Finally, gauranteed by \(\mathbb{X}\) being a preorder category we have

\[(\alpha \otimes \beta)_{x'} = \beta_{G_1^{\text{o}}x'}\circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x', G_1^{\text{o}}x'}(\alpha_{x'}) \sqsubseteq\beta_{G_1^{\text{o}}x}\circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x, G_1^{\text{o}}x}(\alpha_{x}) = (\beta \otimes \alpha)_x.\]

  • Given a pair of objects \(x,y \in \mathcal{O}^{\mathbb{X}}\) and loose arrow \(f : x \not\rightarrow y\) then

\[(\alpha \otimes \beta)_y \circ (F_1 \otimes F_2)^{\lambda}_{x,y}(f)\]

\[= (\beta_{G_1^{\text{o}} y} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F^{\text{o}}_1 y, G^{\text{o}}_1 y}(\alpha_y)) \circ^{\mathbb{X}} (F_1 \otimes F_2)^{\lambda}_{x,y}(f)\]

\[\simeq \beta_{G_1^{\text{o}} y} \circ^{\mathbb{X}} ((F_2)^{\lambda}_{F^{\text{o}}_1 y, G^{\text{o}}_1 y}(\alpha_y)) \circ^{\mathbb{X}} (F_1 \otimes F_2)^{\lambda}_{x,y}(f))\]

\[= \beta_{G_1^{\text{o}} y} \circ^{\mathbb{X}} ((F_2)^{\lambda}_{F^{\text{o}}_1 y, G^{\text{o}}_1 y}(\alpha_y) \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x,F_1^{\text{o}}y}((F_1)^{\lambda}_{x,y}(f))) \]

\[ \simeq \beta_{G_1^{\text{o}}y} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F^{\text{o}}_1 x, G^{\text{o}}_1 y}(\alpha_y \circ^{\mathbb{X}} (F_1)^{\lambda}_{x,y}(f))\]

\[ \simeq \beta_{G_1^{\text{o}}y} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F^{\text{o}}_1 x, G^{\text{o}}_1 y}((G_1)^{\lambda}_{x,y}(f) \circ^{\mathbb{X}} \alpha_x)\]

\[ \simeq \beta_{G_1^{\text{o}}y} \circ^{\mathbb{X}} ((F_2)^{\lambda}_{G^{\text{o}}_1 x, G^{\text{o}}_1 y}((G_1)^{\lambda}_{x,y}(f)) \circ^{\mathbb{X}} (F_2)^{\lambda}_{F^{\text{o}}_1 x, G^{\text{o}}_1 x}(\alpha_x))\]

\[ \simeq (\beta_{G_1^{\text{o}}y} \circ^{\mathbb{X}} (F_2)^{\lambda}_{G^{\text{o}}_1 x, G^{\text{o}}_1 y}((G_1)^{\lambda}_{x,y}(f))) \circ^{\mathbb{X}} (F_2)^{\lambda}_{F^{\text{o}}_1 x, G^{\text{o}}_1 x}(\alpha_x)\]

\[ \simeq ((G_2)^{\lambda}_{G^{\text{o}}_1 x, G^{\text{o}}_1 y}((G_1)^{\lambda}_{x,y}(f)) \circ^{\mathbb{X}} \beta_{G_1^{\text{o}}x}) \circ^{\mathbb{X}} (F_2)^{\lambda}_{F^{\text{o}}_1 x, G^{\text{o}}_1 x}(\alpha_x)\]

\[ \simeq (G_2)^{\lambda}_{G^{\text{o}}_1 x, G^{\text{o}}_1 y}((G_1)^{\lambda}_{x,y}(f)) \circ^{\mathbb{X}}( \beta_{G_1^{\text{o}}x} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F^{\text{o}}_1 x, G^{\text{o}}_1 x}(\alpha_x))\]

\[ = (G_2)^{\lambda}_{G^{\text{o}}_1 x, G^{\text{o}}_1 y}((G_1)^{\lambda}_{x,y}(f)) \circ^{\mathbb{X}} (\alpha \otimes \beta)_x\]

\[ = (G_1 \otimes G_2)^{\lambda}_{x,y}(f) \circ^{\mathbb{X}} (\alpha \otimes \beta)_x;\]

Lemma 2 (Verifying the assignment satisfies the definition of monoidal preorder category)  

  • Given \(G_1 \sqsubseteq F_1, G_2 \sqsubseteq F_2\) pseudo preorder endofunctors of \(\mathbb{X}\) and let \(x \in \mathcal{O}^{\mathbb{X}}\) then,

\[(G_1 \otimes G_2)^{\text{o}}x = G_2^{\text{o}}(G_1^{\text{o}}x) \sqsubseteq G_2^{\text{o}}(F_1^{\text{o}}x) \sqsubseteq F_2^{\text{o}}(F_1^{\text{o}}x) = (F_1 \otimes F_2)^{\text{o}}x;\]

and thus \(G_1 \otimes G_2 \sqsubseteq F_1 \otimes F_2\);

  • Given \(G_1 \sqsubseteq F_1\), \(G_2 \sqsubseteq F_2\), \(H_1 \sqsubseteq K_1\), \(H_2 \sqsubseteq K_2\) pseudo preorder endofunctors on \(\mathbb{X}\) and loose transformations \(\alpha : G_1 \not\rightarrow H_1\), \(\beta : G_2 \not\rightarrow H_2\), \(\gamma : F_1 \not\rightarrow K_1\), \(\delta : F_2 \not\rightarrow K_2\) such that \(\alpha \simeq \gamma\) and \(\beta \simeq \delta\). Let \(x \in \mathcal{O}^{\mathbb{X}}\), then

\[(\alpha \otimes \beta)_x = \beta_{H_1^{\text{o}}x} \circ^{\mathbb{X}} (G_2)^{\lambda}_{G_1^{\text{o}}x,H_1^{\text{o}}x}(\alpha_x)\]

\[\simeq \beta_{K_1^{\text{o}}x} \circ^{\mathbb{X}} (G_2)^{\lambda}_{G_1^{\text{o}}x,H_1^{\text{o}}x}(\alpha_x) \]

\[\simeq \delta_{K_1^{\text{o}}x} \circ^{\mathbb{X}} (G_2)^{\lambda}_{G_1^{\text{o}}x,H_1^{\text{o}}x}(\alpha_x) \]

\[\simeq \delta_{K_1^{\text{o}}x} \circ^{\mathbb{X}} (G_2)^{\lambda}_{F_1^{\text{o}}x,K_1^{\text{o}}x}(\gamma_x) \]

\[= (\gamma \otimes \delta)_x.\]

Which implies that \(\alpha \otimes \beta \simeq \gamma \otimes \beta\).

  • Given \(F_1, F_2\) pseudo preorder endofunctors on \(\mathbb{X}\), we have loose transformations \(\text{id}_{F_1} : F_1 \not\rightarrow F_1\) and \(\text{id}_{F_2} : F_2 \not\rightarrow F_2\). Let \(x \in \mathcal{O}^{\mathbb{X}}\), then

\[(\text{id}_{F_1} \otimes \text{id}_{F_2})_x = (\text{id}_{F_2})_{F_1^{\text{o}}x} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x, F_1^{\text{o}}x}((\text{id}_{F_1})_x)\]

\[= \text{id}_{F_2^{\text{o}}(F_1^{\text{o}}x)} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x, F_1^{\text{o}}x}(\text{id}_{F_1^{\text{o}}x})\]

\[\simeq (F_2)^{\lambda}_{F_1^{\text{o}}x, F_1^{\text{o}}x}(\text{id}_{F_1^{\text{o}}x}) \simeq \text{id}_{F_2^{\text{o}}(F_1^{\text{o}}x)} = \text{id}_{(F_1 \otimes F_2)^{\text{o}}x}.\]

Which implies that \(\text{id}_{F_1} \otimes \text{id}_{F_2} \simeq \text{id}_{F_1 \otimes F_2}\).

  • Given \(F_1, F_2, G_1, G_2, H_1, H_2\) pseudo preorder endofunctors on \(\mathbb{X}\), and loose transformations \(\alpha : F_1 \not\rightarrow G_1\), \(\beta : F_2 \not\rightarrow G_2\), \(\gamma : G_1 \not\rightarrow H_1\), \(\delta : G_2 \not\rightarrow H_2\). Let \(x \in \mathcal{O}^{\mathbb{X}}\), then

\[[(\gamma \circ \alpha) \otimes (\delta \circ \beta)]_x = (\delta \circ \beta)_{H_1^{\text{o}}x} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x, H_1^{\text{o}}x}([\gamma \circ \alpha]_x)\]

\[= (\delta_{H_1^{\text{o}}x} \circ^{\mathbb{X}} \beta_{H_1^{\text{o}}x}) \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x, H_1^{\text{o}}x}(\gamma_x \circ^{\mathbb{X}} \alpha_x)\]

\[\simeq (\delta_{H_1^{\text{o}}x} \circ^{\mathbb{X}} \beta_{H_1^{\text{o}}x}) \circ^{\mathbb{X}} ((F_2)^{\lambda}_{G_1^{\text{o}}x, H_1^{\text{o}}x}(\gamma_x) \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x, G_1^{\text{o}}x}(\alpha_x))\]

\[\simeq \delta_{H_1^{\text{o}}x} \circ^{\mathbb{X}} [\beta_{H_1^{\text{o}}x} \circ^{\mathbb{X}} ((F_2)^{\lambda}_{G_1^{\text{o}}x, H_1^{\text{o}}x}(\gamma_x) \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x, G_1^{\text{o}}x}(\alpha_x))] \]

\[\simeq \delta_{H_1^{\text{o}}x} \circ^{\mathbb{X}} [(\beta_{H_1^{\text{o}}x} \circ^{\mathbb{X}} (F_2)^{\lambda}_{G_1^{\text{o}}x, H_1^{\text{o}}x}(\gamma_x)) \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x, G_1^{\text{o}}x}(\alpha_x)] \]

\[\simeq \delta_{H_1^{\text{o}}x} \circ^{\mathbb{X}} [((G_2)^{\lambda}_{G_1^{\text{o}}x, H_1^{\text{o}}x}(\gamma_x) \circ^{\mathbb{X}} \beta_{G_1^{\text{o}}x}) \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x, G_1^{\text{o}}x}(\alpha_x)]\]

\[\simeq \delta_{H_1^{\text{o}}x} \circ^{\mathbb{X}} [(G_2)^{\lambda}_{G_1^{\text{o}}x, H_1^{\text{o}}x}(\gamma_x) \circ^{\mathbb{X}} (\beta_{G_1^{\text{o}}x} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x, G_1^{\text{o}}x}(\alpha_x))]\]

\[\simeq (\delta_{H_1^{\text{o}}x} \circ^{\mathbb{X}} (G_2)^{\lambda}_{G_1^{\text{o}}x, H_1^{\text{o}}x}(\gamma_x)) \circ^{\mathbb{X}} (\beta_{G_1^{\text{o}}x} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}}x, G_1^{\text{o}}x}(\alpha_x))\]

\[= (\gamma \otimes \delta)_x \circ^{\mathbb{X}} (\alpha \otimes \beta)_{x} = [(\gamma \otimes \delta) \circ (\alpha \otimes \beta)]_x\]

Which implies \((\gamma \circ \alpha) \otimes (\delta \circ \beta) = (\gamma \otimes \delta) \circ (\alpha \otimes \beta)\).

  • Given \(F_1, F_2, F_3, G_1, G_2, G_3\) pseudo preorder endofunctors on \(\mathbb{X}\), and loose transformations \(\alpha : F_1 \not\rightarrow G_1\), \(\beta : F_2 \not\rightarrow G_2\), \(\gamma : F_3 \not\rightarrow G_3\). Let \(x \in \mathcal{O}^{\mathbb{X}}\), then

\[[(F_1 \otimes F_2) \otimes F_3]^{\text{o}}x = F_3^{\text{o}}([F_1 \otimes F_2]^{\text{o}}x) = F_3^{\text{o}}(F_2^{\text{o}}[F_1^{\text{o}}x])\]

\[= (F_2 \otimes F_3)^{\text{o}}[F_1^{\text{o}}x] = (F_1 \otimes (F_2 \otimes F_3))^{\text{o}}x.\]

Furthermore, let \(x,y \in \mathcal{O}^{\mathbb{X}}\) and \(f \in \text{hom}_{\lambda}^{\mathbb{X}}(x,y)\), then

\[[(F_1 \otimes F_2) \otimes F_3]^{\lambda}_{x,y} \ f = (F_3)^{\lambda}_{(F_1 \otimes F_2)^{\text{o}} x, (F_1 \otimes F_2)^{\text{o}} y}[(F_1 \otimes F_2)^{\lambda}_{x,y} \ f] \]

\[= (F_3)^{\lambda}_{F_2^{\text{o}}(F_1^{\text{o}} x), F_2^{\text{o}}(F_1^{\text{o}} y)}[(F_2)^{\lambda}_{F_1^{\text{o}}x, F_1^{\text{o}} y}((F_1)^{\lambda}_{x,y} \ f )]\]

\[= (F_2 \otimes F_3)^{\lambda}_{F_1^{\text{o}} x, F_1^{\text{o}} y}[(F_1)^{\lambda}_{x,y} \ f] = [F_1 \otimes (F_2 \otimes F_3)]^{\lambda}_{x,y} \ f.\]

Which altogether implies \((F_1 \otimes F_2) \otimes F_3 \simeq F_1 \otimes (F_2 \otimes F_3)\).

Let \(x \in \mathcal{O}^{\mathbb{X}}\), then

\[[(\alpha \otimes \beta) \otimes \gamma]_x = \gamma_{(G_1 \otimes G_2)^{\text{o}} x} \circ^{\mathbb{X}} (F_3)^{\lambda}_{(F_1 \otimes F_2)^{\text{o}}x, (G_1 \otimes G_2)^{\text{o}} x}[(\alpha \otimes \beta)_x]\]

\[= \gamma_{G_2^{\text{o}}(G_1^{\text{o}} x)} \circ^{\mathbb{X}} (F_3)^{\lambda}_{(F_1 \otimes F_2)^{\text{o}}x, (G_1 \otimes G_2)^{\text{o}} x}[\beta_{G_1^{\text{o}} x} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}} x, G_1^{\text{o}} x }(\alpha_x)]\]

\[= \gamma_{G_2^{\text{o}}(G_1^{\text{o}} x)} \circ^{\mathbb{X}} (F_3)^{\lambda}_{F_2^{\text{o}}(F_1^{\text{o}}x), G_2^{\text{o}}(G_1^{\text{o}} x)}[\beta_{G_1^{\text{o}} x} \circ^{\mathbb{X}} (F_2)^{\lambda}_{F_1^{\text{o}} x, G_1^{\text{o}} x }(\alpha_x)]\]

\[\simeq \gamma_{G_2^{\text{o}}(G_1^{\text{o}} x)} \circ^{\mathbb{X}} ((F_3)^{\lambda}_{F_2^{\text{o}}(G_1^{\text{o}}x), G_2^{\text{o}}(G_1^{\text{o}} x)}[\beta_{G_1^{\text{o}} x}] \circ^{\mathbb{X}} (F_3)^{\lambda}_{F_2^{\text{o}}(F_1^{\text{o}}x), F_2^{\text{o}}(G_1^{\text{o}} x)}[(F_2)^{\lambda}_{F_1^{\text{o}} x, G_1^{\text{o}} x }(\alpha_x)])\]

\[= \gamma_{G_2^{\text{o}}(G_1^{\text{o}} x)} \circ^{\mathbb{X}} ((F_3)^{\lambda}_{F_2^{\text{o}}(G_1^{\text{o}}x), G_2^{\text{o}}(G_1^{\text{o}} x)}[\beta_{G_1^{\text{o}} x}] \circ^{\mathbb{X}} (F_2 \otimes F_3)^{\lambda}_{F_1^{\text{o}}, G_1^{\text{o}} x}(\alpha_x))\]

\[\simeq (\gamma_{G_2^{\text{o}}(G_1^{\text{o}} x)} \circ^{\mathbb{X}} (F_3)^{\lambda}_{F_2^{\text{o}}(G_1^{\text{o}}x), G_2^{\text{o}}(G_1^{\text{o}} x)}[\beta_{G_1^{\text{o}} x}]) \circ^{\mathbb{X}} (F_2 \otimes F_3)^{\lambda}_{F_1^{\text{o}}, G_1^{\text{o}} x}(\alpha_x)\]

\[= (\beta \otimes \gamma)_{G_1^{\text{o}} x} \circ^{\mathbb{X}} (F_2 \otimes F_3)^{\lambda}_{F_1^{\text{o}}, G_1^{\text{o}} x}(\alpha_x) \]

\[= [\alpha \otimes (\beta \otimes \gamma)]_x.\]

Which implies \((\alpha \otimes \beta) \otimes \gamma \simeq \alpha \otimes (\beta \otimes \gamma)\).

  • Finally, \(\nu : \text{id}_{\mathbb{X}} \not\rightarrow\text{id}_{\mathbb{X}}\), defined on components as, for \(x \in \mathcal{O}^{\mathbb{X}}\) \(\nu_x = \text{id}_x : x \not\rightarrow x\). Note that \(\text{id}_{\text{id}_{\mathbb{X}}} : \text{id}_{\mathbb{X}} \not\rightarrow\text{id}_{\mathbb{X}}\) has components for each \(x \in \mathcal{O}^{\mathbb{X}}\) \((\text{id}_{\text{id}_{\mathbb{X}}})_x = \text{id}_{(\text{id}_{\mathbb{X}})^{\text{o}}x} = \text{id}_{x}\) meaning \(\nu \simeq \text{id}_{\text{id}_{\mathbb{X}}}\). By definition, \(\text{id}_{\mathbb{X}}\) is the unit for the composition in \(\mathbb{X}^{\mathbb{X}}\).
